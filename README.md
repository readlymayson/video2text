# Video-to-Text: Извлечение аудио и расшифровка видео/аудио

Приложение для автоматического извлечения аудиодорожки из видеофайлов или прямой обработки аудиофайлов и их расшифровки с помощью технологии Whisper от OpenAI.

## 🚀 Возможности

- **Извлечение аудио** из популярных форматов видео (MP4, AVI, MKV, MOV и др.)
- **Прямая поддержка аудио** форматов (MP3, WAV, FLAC, M4A и др.)
- **Расшифровка речи** с помощью моделей Whisper (tiny, base, small, medium, large)
- **Автоопределение языка** или ручной выбор
- **Поддержка множества языков** (русский, английский, испанский, французский и др.)
- **Прогресс-бары** для отслеживания процесса
- **Сохранение результатов** в текстовый файл с кодировкой UTF-8
- **Windows совместимость** с поддержкой кириллицы

## 📋 Требования

- **Python 3.8+**
- **FFmpeg** (для обработки видео/аудио)
- **Оперативная память**: минимум 4 ГБ (рекомендуется 8+ ГБ)
- **Видеокарта**: NVIDIA GPU с CUDA (опционально, ускоряет работу)

## 🛠️ Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd video-to-text
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Установка FFmpeg

#### Windows:
- Скачайте FFmpeg с [официального сайта](https://ffmpeg.org/download.html)
- Добавьте путь к `ffmpeg.exe` в переменную окружения PATH
- Или используйте Chocolatey: `choco install ffmpeg`

#### Linux:
```bash
sudo apt update && sudo apt install ffmpeg
```

#### macOS:
```bash
brew install ffmpeg
```

## 📖 Использование

### Базовое использование

```bash
# Обработка видео
python main.py video.mp4

# Обработка аудио
python main.py audio.mp3

# Через батник на Windows
run.bat video.mp4
run.bat audio.mp3
```

### Расширенные параметры

```bash
python main.py input_file [ОПЦИИ]
```

#### Доступные опции:

- `input_file`: Путь к видео или аудиофайлу
  - `tiny` - самая быстрая, наименее точная
  - `base` - баланс скорости и точности (по умолчанию)
  - `small` - лучше точность, медленнее
  - `medium` - высокая точность
  - `large` - максимальная точность

- `--language, -l`: Язык аудио
  - `auto` - автоопределение (по умолчанию)
  - `ru` - русский
  - `en` - английский
  - `es` - испанский
  - `fr` - французский
  - `de` - немецкий
  - Другие: `it`, `pt`, `zh`, `ja`, `ko`, `ar`, `hi`, `tr`, `pl`, `uk`

- `--output, -o`: Путь к выходному файлу с транскрипцией
  - По умолчанию: рядом с видео с расширением `.txt`

- `--keep-audio, -k`: Сохранить извлеченный аудиофайл после обработки

- `--audio-output, -a`: Путь для сохранения извлеченного аудио
  - По умолчанию: рядом с видео с расширением `.wav`

- `--verbose, -v`: Подробный вывод информации

- `--log-file`: Путь к файлу для записи логов

### Примеры использования

```bash
# Простая расшифровка видео
python main.py my_video.mp4

# Простая расшифровка аудио
python main.py my_audio.mp3

# Расшифровка с указанием языка и модели
python main.py video.mp4 --model medium --language ru

# Сохранение в определенный файл
python main.py audio.wav --output transcript.txt
```

## 🔧 Устранение проблем

### "ModuleNotFoundError" при запуске
Убедитесь, что установлены все зависимости:
```bash
pip install -r requirements.txt
```

### "ffmpeg not found" ошибка
Установите FFmpeg и добавьте его в PATH.

### Проблемы с CUDA/GPU
Если GPU недоступна, приложение автоматически переключится на CPU.

### Память переполнена
- Используйте меньшую модель (`tiny` или `base`)
- Закройте другие приложения
- Добавьте больше оперативной памяти

### Проблемы с кириллицей на Windows
Используйте `run.bat` вместо прямого запуска Python - он устанавливает правильную кодировку.
