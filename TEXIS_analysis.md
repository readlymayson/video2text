# Анализ транскрибации: Внедрение сквозной аналитики

## Общая информация

- **Тип документа**: Транскрибация видео/аудио
- **Язык**: Русский (ru)
- **Модель распознавания**: medium
- **Длительность**: ~53 минуты (3224 секунд)
- **Формат**: Подготовка к совещанию по внедрению сквозной аналитики

---

## Основная цель проекта

**Главная задача**: Внедрение сквозной аналитики для расчета эффективности каналов привлечения клиентов.

**Ключевая проблема**: На данный момент в Яндекс.Метрике отслеживаются только визиты, что является косвенным показателем эффективности маркетинга. Необходимо связать визиты с реальными лидами и сделками.

---

## Каналы коммуникации

### 1. Формы на сайте
**Типы форм:**
- Форма feedback (обратная связь)
- Форма find cost (узнать стоимость)
- Форма callback (заказать обратный звонок)
- Форма сервис и гарантия
- Связаться с сервисным центром

**Требования:**
- Лид создается автоматически в Bitrix24
- Передача данных в Яндекс.Метрику и Bitrix24

**Передаваемые данные:**
- Идентификатор формы (канал коммуникации)
- URL страницы
- Реферер
- UTM-метки
- Client ID (для склейки данных)

### 2. Email
**Почтовые адреса:**
- npc.info
- npc.сервис
- Контакты сотрудников
- Найти контакты сотрудника

**Особенности:**
- Лиды НЕ создаются автоматически
- Обработка вручную: девочка pre-sales разбирает письма
- Создание лида вручную из почтового обращения

**Вопросы для обсуждения:**
- Email tracking: статический или динамический?
- Обсуждение с Валентиной о необходимости email tracking
- Проблемы с отслеживанием (копирование адреса, использование внешних почтовых клиентов)

### 3. Входящие звонки
**Телефонные номера:**
- 8-800 (основной)
- 495 (с добавочными номерами)

**Требования:**
- Call tracking обязателен
- Лид создается автоматически
- Разделение по номерам (8-800 и 495 - разные каналы)

**Передаваемые данные:**
- Идентификатор звонка (канал коммуникации)
- URL страницы (с которой был звонок)
- Реферер
- UTM-метки
- Client ID

**Вопросы для обсуждения:**
- Call tracking на два номера: как реализуется?
- Call tracking для номеров с добавочными: как работает?
- Вариант: поставить call tracking только на 8-800, на 495 - ручное создание лидов
- Обсуждение с Валентиной и Александром Сучковым

**Важно:**
- Исходящие звонки НЕ создают лиды (относятся к оффлайн-конверсии)
- Лид должен быть создан сначала, затем из него делается звонок

### 4. Мессенджеры
**Типы:**
- WhatsApp
- Telegram
- Max (планируется, когда доработают интеграцию на стороне Bitrix)

**Особенности:**
- Работают через стандартный битриксовский виджет
- Все работают через WhatsApp (технически)
- Лид создается автоматически

**Текущее состояние:**
- Идентификатор обращения передается (называется "источник", нужно переименовать в "канал коммуникации")
- НЕ передаются: URL страницы, реферер, UTM-метки, Client ID

**Требования:**
- WhatsApp должен забирать метки и прокидывать их в Bitrix24
- Если WhatsApp не умеет - искать другой коннектор

### 5. Оффлайн коммуникации
**Типы:**
- Активные продажи
- BTL (Business to Lead)
- Выставки
- Визитки
- Встречи

**Особенности:**
- Лид создается вручную
- Передается только канал коммуникации
- Дополнительные метки не нужны

## Структура данных в Bitrix24

### Поля в карточке лида

**Канал коммуникации** (переименовать из "источник"):
- Форма: feedback, find cost, callback, сервис
- Email: npc.info, npc.сервис, и т.д.
- Звонок: входящий звонок на 8-800, входящий звонок на 495
- Мессенджер: WhatsApp, Telegram, Max
- Оффлайн: активные продажи, BTL

**Дополнительные поля:**
- URL страницы
- Реферер
- UTM-метки (с вложенностью через data layer)
- Client ID

### Требования к UTM-меткам

**Важно:** Передача UTM-меток с вложенностью (data layer)

**Пример вложенности:**
- Яндекс.Директ → CPC → Рекламные компании → Ключевые слова
- Другие поиски → CPC → Компании → Ключевики

**Проблема:** В отчете "Источники заказов и CRM" вложенность не доработана - теряется после первого уровня.

## Воронка лидов в Bitrix24

### Этапы воронки лидов:

1. **Новый лид** (автоматическое создание)
   - Канал коммуникации
   - URL, реферер, UTM-метки
   - Client ID

2. **Обработка pre-sales** (девочка-менеджер)
   - Определение типа: сервисные обращения / продажи / спам
   - Если спам → "Квалификация не пройдена, не целевой лид"
   - Если сервис → в сервисные
   - Если продажи → в продажи

3. **Взято в работу** (менеджер)
   - Менеджер начинает работу с лидом

4. **Квалификация пройдена**
   - Создание контакта
   - Создание компании
   - Создание сделки
   - Комбинации: контакт+компания, контакт+компания+сделка

### Результаты воронки лидов:

Из лида может быть создано:
- **Контакт** (база данных)
- **Компания**
- **Сделка** (в одной из воронок продаж)

---

## Ключевые метрики (первый этап)

### Конверсии (в штуках):

1. **Конверсия из визитов в лиды**
   - Пример: 1000 визитов → 100 лидов
   - Показывает эффективность каналов привлечения

2. **Конверсия из лидов в сделки**
   - Пример: 100 лидов → 20 сделок
   - Показывает качество обработки лидов

3. **Конверсия из лидов в контакты**
   - Пример: 100 лидов → 30 контактов (20 сделок + 10 контактов без сделки)
   - Показывает общий охват базы данных

### Пример из другого проекта:

- Поисковые системы: 7654 визита → 144 лида → 7 сделок (конверсия 1.17%)
- Реклама: 749 визитов → 56 лидов → 7+ сделок (конверсия 7%+)

**Вывод:** Реклама более конвертируема, чем SEO. Нужно работать над улучшением SEO-канала.

## Этапы реализации проекта

### Этап 1: Базовый (текущий фокус)

**Цель:** Считать конверсии в штуках

**Задачи:**
- Настроить передачу данных из всех каналов в Bitrix24 и Яндекс.Метрику
- Настроить call tracking
- Настроить интеграцию мессенджеров
- Настроить UTM-метки с вложенностью
- Очистить список каналов коммуникации в Bitrix24
- Переименовать "источник" в "канал коммуникации"

**Результат:**
- Конверсия из визитов в лиды
- Конверсия из лидов в сделки
- Конверсия из лидов в контакты

### Этап 2: Финансовые метрики

**Цель:** Подключить затраты и считать финансовые показатели

**Задачи:**
- Интеграция Яндекс.Директ с Метрикой
- Загрузка затрат на рекламу
- Загрузка затрат на SEO (через сервис)
- Загрузка затрат на SMM, CBS
- Оффлайн затраты (выставки, публикации)

**Метрики:**
- **CPC** (Cost Per Contact) - стоимость привлечения контакта
- **CPL** (Cost Per Lead) - стоимость привлечения лида
- **ROMI** (Return on Marketing Investment) - возврат маркетинговых инвестиций

**Данные из Bitrix24:**
- Стоимость каждой сделки
- Распределение выручки по каналам

### Этап 3: Визуализация (часть этапа 2)

**Инструмент:** Яндекс.ДатаЛенс (через Яндекс.Облако)

**Дашборды:**
- Для отдела продаж
- Для коммерческого директора
- Для генерального директора

**Дополнительные данные:**
- Интеграция с Bitrix24 через API (затраты, дополнительные метрики)
- Личный кабинет (статистика использования, скачивание BIM-моделей)
